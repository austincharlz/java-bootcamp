Source code is what the dev writes which is turned into bytecode by the compiler. The JVM is what executes the bytecode.
These three things are what allows "Write Once, Run Anywhere" to be true

Pre-Lab Questions:
1. Why Bytecode? Bytecode allows Java to be run on any machine because bytecode is used as a bridge before compiling for the specific CPU/system. 
2. Class name vs file path? Java omits the .class file because it is looking for the class name, not the file path.
